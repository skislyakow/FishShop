# Triage Labels

Skills говорят на языке пяти канонических ролей triage. Этот файл сопоставляет роли строкам
меток, реально используемым в трекере.

| Label в mattpocock/skills | Label в нашем трекере | Значение |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Мейнтейнеру нужно оценить issue |
| `needs-info` | `needs-info` | Ждём от автора дополнительной информации |
| `ready-for-agent` | `ready-for-agent` | Полностью специфицировано, можно отдавать AFK-агенту |
| `ready-for-human` | `ready-for-human` | Требует реализации человеком |
| `wontfix` | `wontfix` | Не будет сделано |

Когда skill упоминает роль (например «apply the AFK-ready triage label»), используй
соответствующую строку из таблицы.

Колонку «Label в нашем трекере» можно менять под свою реальную лексику.
