# Git-репозиторий как единственный канал синхронизации кода

Разработка идёт на двух машинах, и единственная связь между ними — публичный git-репозиторий.
Через него ходят код, схема content-types, конфиги и документация; секреты и бинарные данные
в него не попадают. Это делает состояние проекта воспроизводимым на любой из машин одной
командой `git pull`.

## Последствия

- `cms/.env` генерируется локально на каждой машине, в git только `.env.example`.
- Бинарник БД и архивы игнорируются (ADR-0003).
- `skills-lock.json` коммитится, а `.agents/skills/` — нет: вторая машина восстанавливает skills
  из lockfile одной командой (`npm run setup`, ADR-0006).
- Репозиторий публичный, поэтому в него нельзя класть ничего личного (токены бота, реальные
  заказы, персональные данные покупателей).
