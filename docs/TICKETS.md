# План работ

Тикеты по уроку. Формат — «трассирующие пули»: каждый тикет даёт работающий срез, который можно
проверить. Зависимости указаны стрелками `←`.

Легенда статусов: `[ ]` — не начат, `[~]` — в работе, `[x]` — готов.

## Этап 2. Telegram-бот (после сдачи урока)

- [x] **T6. Каркас бота.** ← T4
  Стек выбран (python-telegram-bot 22 + Redis — ADR-0007), скелет поднят. Проверка пройдена:
  `bot/fsm_example.py` отвечает в тестовом чате (`/start` → «Привет!», дальше эхо), состояния
  диалогов в Redis под ключами `state:<chat_id>`, зависимости в `bot/` (PTB 22.8, redis 8.1).

- [x] **T7. Каталог в inline-кнопках.** ← T6, T4
  Товары как inline-меню. Проверка: кнопки ведут по каталогу, показывают цену и фото.
  Разделов (`Category`) в модели нет — см. T3. `/start` присылает по кнопке на каждый товар
  (`callback_data` — `document_id`), нажатие показывает карточку (фото, название, цена, описание,
  «← К списку») через состояние `HANDLE_MENU`, сообщение с меню удаляется. Картинка скачивается и
  отправляется файлом. Telegram принимает и jpg, и webp — проверено на всех 10 товарах, конвертация
  не нужна; Pillow остаётся запасным вариантом для формата, который он не возьмёт.

- [x] **T7.1. Возврат из карточки отдельным состоянием.** (шаг урока «Добавьте возможность вернуться»)
  Кнопка «← Назад» на карточке, карточку обслуживает состояние `HANDLE_DESCRIPTION`, возврат — в
  `HANDLE_MENU`; `START` остаётся точкой входа `/start`. Для пользователя поведение прежнее,
  разница видна в Redis — и на `HANDLE_DESCRIPTION` ляжет обработка кнопок корзины.

- [~] **T8. Оформление заказа.** ← T7
  Собрать корзину, спросить имя и телефон, создать `Order` в Strapi. Проверка: заказ появляется
  в админке Strapi. Сделано: модель корзины — `Cart` (уникальный `telegram_user_id`) и `CartItem`
  (`fish` + `quantity_kg`), Draft & Publish у них выключен (ADR-0008); в админке заведены три
  покупателя с 1–2 товарами. Кнопка «Добавить в корзину» на карточке товара создаёт корзину при
  первом нажатии и кладёт в неё `CartItem`, повторное нажатие увеличивает `quantity_kg`
  (`StrapiClient.add_item`). Кнопка «Моя корзина» есть и в меню, и в карточке: показывает
  состав и сумму текстом (`get_cart` + состояние `HANDLE_CART`). Осталось: изменение и удаление
  позиций, ввод имени и телефона, content-types `Customer`, `Order`, `OrderItem`.

- [ ] **T9. «Магазин мечты».** ← T8
  Довести UX: пустые состояния, ошибки, подтверждение заказа.

## Как вести тикеты

- Крупные задачи — в GitHub Issues, метки triage: `needs-triage`, `needs-info`,
  `ready-for-agent`, `ready-for-human`, `wontfix` (см. `docs/agents/`).
- Ветка на тикет: `t<номер>-<слаг>`.
- Готово = проверка из тикета проходит на обеих машинах.
