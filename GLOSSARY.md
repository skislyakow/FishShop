# FishShop

Интернет-магазин рыбы и морепродуктов Дениса. Товары и заказы живут в Strapi,
покупатель взаимодействует с магазином через Telegram-бота.

## Language

**Товар** (`fish`):
Единица продажи в каталоге — вид рыбы или морепродукта с ценой за килограмм, фото,
описанием и остатком. Цена хранится за килограмм, а не за штуку.
_Avoid_: SKU, позиция, item, продукт

**Раздел** (`category`):
Группа товаров, объединяющая их в каталоге (например «Красная рыба», «Икра»).
_Avoid_: категория, тег, подборка

**Каталог**:
Опубликованный набор разделов и товаров, который видит покупатель в боте.
В каталог попадают только опубликованные записи.
_Avoid_: витрина, ассортимент

**Покупатель** (`customer`):
Человек, оформляющий заказ в Telegram. Идентифицируется по `telegram_user_id`,
имя и телефон появляются только на этапе оформления.
_Avoid_: клиент, пользователь, аккаунт, user

**Заказ** (`order`):
Намерение покупателя купить набор товаров, зафиксированное ботом.
Содержит контакт, состав и статус.
_Avoid_: покупка, транзакция, cart, корзина

**Позиция заказа** (`order-item`):
Одна строка внутри заказа: товар, количество и цена на момент оформления.
Цена «замораживается», чтобы изменения прайса не переписывали прошлые заказы.
_Avoid_: строка, line, item

**Статус заказа**:
Состояние заказа в обработке: `new` → `confirmed` → `shipped` → `done` (или `cancelled`).
_Avoid_: state, фаза

**Магазин мечты**:
Формулировка Дениса для критерия готовности: покупатель оформляет заказ целиком
внутри Telegram, без перехода на сайт.

## Strapi

**Content-Type**:
Модель данных Strapi. Для магазина определены `fish`, `category`, `customer`, `order`.
_Avoid_: схема, таблица, коллекция

**Черновик / Публикация** (`draftAndPublish`):
Состояние записи в Strapi. Бот и API по умолчанию видят только опубликованное.
_Avoid_: active/inactive, enabled

**API-токен**:
Ключ из Strapi, которым бот авторизует свои запросы к REST API.
Выдаётся отдельно на каждой машине и в git не попадает.
_Avoid_: пароль, ключ, secret
