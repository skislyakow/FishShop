# Strapi-проект на JavaScript, а не TypeScript

Strapi 5 по умолчанию создаёт TypeScript-проект, но здесь берём JavaScript (`--js`). Причина:
это учебный урок курса devman, где CMS описывается именно как JavaScript-проект, а аудитория
приходит из Python. JS убирает лишний слой (типы, сборка, конфиг TS), не мешая задаче.

## Последствия

- Меньше порога входа и конфигурации для новичка.
- Нет статических типов на серверной логике Strapi — компенсируем внимательностью и тестами
  там, где появится своя логика.
- Если проект перерастёт учебный (свой код в боте/сервисах) — стоит пересмотреть и, возможно,
  перейти на TS отдельным ADR.
