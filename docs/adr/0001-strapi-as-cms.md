# Strapi как CMS и бэкенд магазина

Заказчик Денис уже работает со Strapi, поэтому магазин делаем на Strapi, а не на самописном
API или Django-админке: это даёт готовую админку, Content-Type Builder, REST API, загрузку медиа
и разграничение прав «из коробки». Цена решения — привязка к экосистеме Strapi/Node.js.

## Рассмотренные варианты

- **Strapi** — выбран: совпадает с продакшеном Дениса, минимум кода для CRUD и API.
- **Самописный REST API (FastAPI/Express)** — гибче, но весь CRUD, админка и загрузка файлов
  пишутся вручную.
- **Django admin** — тоже даёт админку, но это второй стек (Python) рядом с Node.js и не
  совпадает с окружением заказчика.
