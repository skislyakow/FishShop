# SQLite как локальная база разработки

Strapi по умолчанию использует SQLite (`cms/.tmp/data.db`) — оставляем её для разработки:
нулевая настройка, одна БД на машину, не нужен внешний сервер. Схема БД при этом не переносится
через SQLite-файл, а восстанавливается из `schema.json`, которые лежат в git.

## Последствия

- БД каждой машины независима и синхронизируется экспортом/импортом (ADR-0003), а не копированием файла.
- Переход на прод-БД (Postgres) — это отдельное решение; SQLite для прода не годится.
