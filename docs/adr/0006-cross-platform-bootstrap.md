# Кроссплатформенный бутстрап окружения на Node-скрипте

Развёртывание окружения (личные skills, зависимости Strapi и будущего Python-бота) выполняется
одной кроссплатформенной командой `npm run setup`, за которой стоит Node-скрипт
`scripts/bootstrap.mjs`. Node выбран потому, что он уже обязателен для Strapi на всех целевых
машинах (две dev-машины на Windows и прод-сервер на Ubuntu), поэтому не добавляет новых
инструментов.

## Рассмотренные варианты

- **PowerShell-скрипт** — нативно для Windows, но не работает на Ubuntu-сервере.
- **bash-скрипт** — родной на Linux, на Windows выполняется только через Git Bash.
- **`just` / Make** — удобный раннер, но требует установки ещё одного инструмента на каждую машину и сервер.
- **Node-скрипт + корневой `package.json`** — выбран: ноль новых инструментов, условия и работа с файлами кроссплатформенны.

## Последствия

- В корне появляется `package.json` без зависимостей — только скрипты `setup` и `setup:prod`.
- Файлы skills (`.agents/skills/`) в git не хранятся и восстанавливаются из `skills-lock.json`
  шагом `setup`; на сервере шаг пропускается (`setup:prod` / `--no-skills`).
- `uv` скрипт не устанавливает, а только проверяет наличие и подсказывает команду установки.
