# Урок 5. Продаём рыбу в Telegram

Исходное задание курса devman, по которому делается проект.

## Сюжет

Денис родился на Камчатке и открыл бизнес по торговле морепродуктами. За 5 лет маленькая
палатка превратилась в интернет-магазин с поставками по всей России. Дойдя до Москвы, Денис
хочет работать с частными клиентами. Но москвичей непросто заманить на сайт: они избалованы
чат-ботами и привыкли покупать не выходя из Instagram или Telegram.

Если москвич не идёт к рыбе, то рыба идёт к москвичу: нужно сделать Telegram-бота, где новые
покупатели смогут оформлять заказы.

## Задача

- Интегрироваться с CMS Дениса.
- Использовать inline-кнопки.
- Сделать «магазин мечты» (по версии Дениса).

## Что нужно знать по условию

- Денис работает со **Strapi**. Доступа к его рабочему магазину нет — нужно поднять **свой проект**.
- CMS написана на JavaScript, поэтому локально нужен **Node.js**.

## Критерий проверки

> Вы создадите магазин в Strapi.

То есть на первом этапе бот не требуется: сначала поднимаем и наполняем Strapi-магазин,
который отдаёт каталог и принимает заказы по REST API.
